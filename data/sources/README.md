# 政策原始文件

本目錄收錄 2026 年（民國 115 年）「300 億元中央擴大租金補貼」相關官方文件，作為 `lib/rules/` 規則檔的**唯一權威依據**。

## 為什麼放在 repo

- **可追責**：規則檔每條規則都能對照原始文件
- **可 diff**：未來官方修正後，可比對新舊版差異
- **自包含**：不依賴政府網站（連結可能失效）

## 對應的純文字版本

`../sources-txt/` 下有對應的 `.txt` 檔（用 `pdftotext -layout` 抽取），方便：
- git diff 追蹤政策變動
- 程式化搜尋條文
- AI 工具讀取

## 規則變動流程

1. 取得新版 PDF
2. 放到本目錄，**檔名加日期後綴**（避免覆蓋舊版）
3. 用 `pdftotext -layout` 重新抽 `.txt`
4. 比對 diff，更新 `lib/rules/`
5. 更新 `lib/constants/policy-version.ts`
6. 在 `data/changelog.json` 加一筆紀錄
